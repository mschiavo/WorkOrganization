# WorkOrganizer v0.5: Leave & PAR Breakdown, Flexible Duration Parser & Calendar Future Status Indicator

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Introdurre la ripartizione dell'assenza tra monte Ferie e monte PAR (sia a giornata intera che frazionata), il parser flessibile delle ore/minuti di permesso (supporto per `3`, `3h`, `50m`, `3h50`, `3h50m`, `3:50`), e la distinzione visiva sul calendario tra giorni passati/odierni consolidati (spunta verde `✓`) e giorni futuri pianificati/compilati (orologino giallo `⏳`).

**Architecture:**
- Dominio: Nuovo modulo `durationParser.ts` (TDD) per parsing e formattazione flessibile delle durate; estensione di `DayStatus` con `'par'` e `'idea_par'`; aggiornamento di `leaveManager.ts` per calcolare consumi sia da causale che da ore esplicite imputate a ferie e par.
- Componenti UI: Input intelligente `DurationInput.tsx` per i permessi; aggiornamento `DayDetailCard.tsx` con causale `PAR` e ripartizione oraria ferie/par; aggiornamento `CalendarDayCard.tsx` con logica temporale (`date <= today` -> `✓`, `date > today` -> `⏳`).
- Branch Git: `feature/ferie-par-flex-input-calendar-status`.

**Tech Stack:** React 19, TypeScript (strict mode), Vite 6, Vitest, Testing Library, Vanilla CSS Modules.

**Spec:** `docs/superpowers/specs/2026-11-04-workorganizer-design.md`

## Global Constraints

- **ABSOLUTELY NO GIT COMMITS TO MAIN/MASTER WITHOUT APPROVAL**: Tutte le modifiche vengono eseguite sul branch `feature/ferie-par-flex-input-calendar-status`.
- **VERSION 0.5**: Versione `0.5.0` in `package.json` e badge `v0.5` in `Header.tsx`.
- **FLEXIBLE DURATION PARSER**: Accettare e interpretare: `3` (3h = 180m), `3h` (180m), `50m` (50m), `3h50` (230m), `3h50m` (230m), `3:50` (230m).
- **CALENDAR INDICATORS**:
  - Giorno passato o odierno compilato/confermato (`date <= today`): spunta verde `✓`.
  - Giorno futuro compilato/pianificato (`date > today`): orologino giallo `⏳` / clock ambra.
- **PAR / FERIE DISTINCTION**: Distinzione visiva e contabile tra Ferie (Viola `#8b5cf6`), PAR (Ciano `#06b6d4`), Idea Ferie (Lilla `#c084fc`) e Idea PAR (Ciano tratteggiato).
