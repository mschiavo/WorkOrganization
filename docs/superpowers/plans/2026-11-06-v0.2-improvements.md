# WorkOrganizer v0.2: Layout Refinement, Inline Status Selector & Punch Time Improvements

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aggiornare l'applicazione alla versione 0.2 implementando i feedback dell'utente: rimozione del layout Tabbed (mantenendo solo Split e Smart Sheet), trasformazione della colonna Stato in menu a tendina interattivo in visualizzazione Sheet, calendario Split a pagina mensile tradizionale senza popup (con selezione stato spostata su DayDetailCard a destra), e inserimento/modifica oraria delle 4 timbrature con pre-compilazione editabile dell'ora attuale.

**Architecture:** Modifiche mirate all'interfaccia utente e alla gestione dell'interazione: eliminazione dei modali/popover per l'assegnazione dello stato a favore di controlli inline e master-detail; aggiornamento del container layout per supportare solo `'split'` e `'smart-sheet'`; potenziamento degli input orari in `TodayHeroWidget` e `DayDetailCard`.

**Tech Stack:** React 19, TypeScript (strict mode), Vite 6, Vitest, Testing Library, Vanilla CSS Modules.

**Spec:** `docs/superpowers/specs/2026-11-04-workorganizer-design.md`

## Global Constraints

- **ABSOLUTELY NO GIT COMMANDS**: L'utente ha vietato qualsiasi operazione git (`git add`, `git commit`, `git checkout`, ecc.).
- **NO POPUPS**: Non usare modali o popup per la selezione delle causali del giorno ("Tendenzialmente, in generale, non sopporto i popup"). Tutte le selezioni devono avvenire inline tramite menu a tendina o pulsanti nel pannello laterale destro.
- **VERSION 0.2**: La versione visibile nell'header e nei file di metadati (`package.json`, `README.md`) deve essere aggiornata a `v0.2` / `0.2.0`.
- **DUE LAYOUT**: Supportare esclusivamente i layout `'split'` e `'smart-sheet'`. Il layout `'tabbed'` deve essere rimosso dai selettori e dalle impostazioni.
- **STRICT TYPING & TDD**: Zero errori TypeScript (`npx tsc`), 100% test passati in Vitest (`npm test`).

## Review Focus

- **Rimozione popup calendario**: Il click su un giorno nel calendario deve limitarsi a selezionarlo (`setSelectedDate(date)`), senza aprire alcun dialog modale.
- **Assegnazione stato su DayDetailCard**: Nella colonna destra di Split, devono comparire comodi pulsanti (o select) per assegnare direttamente lo stato (Presenza, Smart, Ferie, Chiusura, Non lavorativo) al giorno selezionato.
- **Menu a tendina Stato in TimbratureTable**: Il cambio di stato da `<select>` nella tabella deve chiamare immediatamente `updateDayStatus` e aggiornare reattivamente colori, conteggi e bilanci.
- **Pulsanti timbratura 4 orari**: Ciascun orario deve poter essere digitato/selezionato partendo dall'ora attuale come valore di default editabile.
- **Retrocompatibilità layout settings**: Se un utente aveva salvato `'tabbed'` in cache, deve fare fallback pulito su `'split'`.
