# WorkOrganizer v0.3: Compact Split Calendar, Keyboard Time Input Fix & Read-Only Sheet Monthly Report

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aggiornare l'applicazione alla versione 0.3 implementando: calendario Split compatto a griglia classica (7 colonne Lun-Dom, 1 riga a settimana, nessun scrolling verticale), risoluzione del bug di inserimento da tastiera dei minuti/ore nei campi timbratura mantenendo il selettore nativo, e conversione della visualizzazione Sheet in report mensile analitico di pura lettura con tutte le statistiche e quadratura economica/oraria (commentando i controlli di inserimento per rapido recupero).

**Architecture:** Componente dedicato `TimeInput` con gestione dello stato locale durante il focus da tastiera per evitare che i re-render di React resettino il buffer di digitazione a due cifre del browser; refactoring della griglia calendario in modalità compatta per adattarsi all'altezza della colonna Split senza scroll; introduzione del componente `MonthlyReportSummary` e prop `readOnly` in `TimbratureTable` per la vista Sheet.

**Tech Stack:** React 19, TypeScript (strict mode), Vite 6, Vitest, Testing Library, Vanilla CSS Modules.

**Spec:** `docs/superpowers/specs/2026-11-04-workorganizer-design.md`

## Global Constraints

- **ABSOLUTELY NO GIT COMMANDS**: L'utente ha vietato qualsiasi operazione git (`git add`, `git commit`, `git checkout`, ecc.).
- **VERSION 0.3**: La versione visibile nell'header e nei metadati (`package.json`, `README.md`) deve essere `v0.3` / `0.3.0`.
- **KEYBOARD TYPING SUPPORT**: L'inserimento da tastiera nei campi orari deve consentire di digitare due cifre (es. "54" nei minuti) senza che il primo numero venga sovrascritto da "04". Il selettore/picker nativo deve rimanere pienamente funzionante.
- **NO SCROLLING IN SPLIT CALENDAR**: Il calendario nella colonna sinistra di Split deve avere una riga per settimana da Lun a Dom con celle compatte, visualizzabile interamente senza scroll verticale.
- **SHEET VIEW READ-ONLY & COMMENTED INPUTS**: Nella vista Sheet non ci devono essere controlli di input o select; i controlli di inserimento sono commentati con spiegazione per poter essere riabilitati rapidamente, e la vista deve fungere da report mensile con tutte le statistiche di presenze, smart, banca ore e buoni pasto.
- **STRICT TYPING & TDD**: Zero errori TypeScript (`npx tsc`), 100% test passati in Vitest (`npm test`).

## Review Focus

- **Digitazione tastiera minuti**: Digitando in sequenza "5" e poi "4" nel segmento dei minuti, l'orario risultante deve essere "HH:54" e non "HH:04".
- **Visualizzazione calendario Split**: 7 colonne esatte (Lun..Dom), 5 o 6 righe settimanali compatte, nessun overflow con scroll verticale.
- **Sheet View pura lettura**: La tabella nella vista Sheet mostra i badge visivi di stato; il tag `<select>` di modifica è commentato; il widget superiore mostra tutte le statistiche di riepilogo del mese.
- **Selettore orario nativo preservato**: L'icona dell'orologio / picker del browser apre regolarmente il selettore orario nativo.
